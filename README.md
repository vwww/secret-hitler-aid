# Secret Hitler Bayesian CFR Advisor (LLM-generated)

A standalone, client-side decision aid for standard Secret Hitler games with 5-10 players. It estimates hidden roles from known information and logged actions, then recommends a move for the current decision phase.

> [!NOTE]
> **LLM-generated code:** This project’s code was generated by a large language model (LLM). Treat it as an experimental prototype; review the code and verify recommendations before relying on them.

## Run

Open `index.html` in a modern browser. No installation, server, or external dependencies are required. Game data stays in the current page and is cleared when the page is reloaded.

## Use

1. Set the player count, your seat and role, current phase, president, nominated chancellor, policy totals, election tracker, and last elected chancellor.
2. Enter roles you know with certainty. For a 5-6 player game as a Fascist, select the known Hitler seat. In those games, Hitler can enter known Fascist seats.
3. For a legislative decision, choose your office and enter the policy cards in your hand using `L` and `F` (three cards as president, two as chancellor).
4. Add public evidence to the action log. For enacted policies and passed governments, enter both relevant seats. For votes and investigations, enter the seat being observed.
5. Select **Find best move**. The analysis shows a recommended action, comparative regret shares, and estimated Fascist probability for each player.

Decision phases include chancellor nomination, government vote, legislative session, veto, and executive powers (investigation, execution, or special election). Keep the board inputs current; the advisor does not automatically infer board state from the action log.

## Model notes

Role estimates enumerate assignments consistent with the standard role counts and roles entered as certain, then weight assignments using logged evidence. Recommendations use hand-authored strategic utilities and regret matching to compare available choices.

This is a lightweight, rule-based advisor, not a full-game Counterfactual Regret Minimization solver or a guarantee of optimal play. Its probabilities depend on the evidence entered and should be treated as estimates, not facts. Confirm legal actions against the table's rules and current board state.
